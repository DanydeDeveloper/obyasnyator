## Retrieval без векторной БД

**Задача:** Находить релевантные части документа для ответа тьютора.
**Решение:** Keyword scoring — считаем сколько раз слова из вопроса встречаются в каждом чанке. Берём top-4. Восстанавливаем оригинальный порядок.

```ts
function scoreChunk(chunk, query) {
  const words = query.toLowerCase().split(/\W+/).filter(w => w.length > 3);
  return words.reduce((score, word) => {
    return score + (chunk.text.toLowerCase().match(new RegExp(word, "g")) ?? []).length;
  }, 0);
}
```

**Почему не embeddings:** Надёжнее для MVP, нулевая инфраструктура, мгновенный старт.

## Structured output от Claude (JSON без мусора)

**Задача:** Получить валидный JSON для квиза/карточек без markdown-обёрток.
**Решение:** Явно просим в промпте `"Return ONLY a JSON array, no markdown"` + стрипаем на случай если всё равно завернёт:

```ts
export function parseJSON<T>(raw: string): T {
  const stripped = raw
    .replace(/^```(?:json)?\s*/i, "")
    .replace(/\s*```\s*$/, "")
    .trim();
  return JSON.parse(stripped) as T;
}
```

## PDF парсинг в Next.js App Router

**Задача:** Парсить PDF на сервере без конфликтов с Edge Runtime.
**Решение:**
```ts
// next.config.ts
serverExternalPackages: ["pdf-parse"]

// route.ts
export const runtime = "nodejs";
const pdfParse = (await import("pdf-parse")).default; // динамический импорт
```

## Flip-анимация карточек без библиотеки

**Задача:** CSS flip эффект для флэшкарточек.
**Решение:** CSS `perspective` + `rotateY` + `backfaceVisibility: hidden`:

```tsx
<div style={{ perspective: "1000px", height: "220px" }}>
  <div style={{
    transformStyle: "preserve-3d",
    transform: flipped ? "rotateY(180deg)" : "rotateY(0deg)",
    transition: "transform 0.5s"
  }}>
    <div style={{ backfaceVisibility: "hidden" }}>/* Front */</div>
    <div style={{ backfaceVisibility: "hidden", transform: "rotateY(180deg)" }}>/* Back */</div>
  </div>
</div>
```

## Синхронизация активного раздела

**Задача:** Подсвечивать в сайдбаре раздел который сейчас виден в документе.
**Решение:** `IntersectionObserver` с `threshold: 0.3` следит за каждой секцией. При клике в сайдбаре — `scrollIntoView({ behavior: "smooth" })`.
