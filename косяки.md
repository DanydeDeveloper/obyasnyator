# Косяки — Объяснятор

Известные проблемы, баги и подводные камни проекта.

---

## Биллинг и API ключи

**Проблема:** Ключ создан, но API возвращает ошибку баланса.
**Симптом:** `"Your credit balance is too low to access the Anthropic API"`
**Причина:** Ключ привязан к аккаунту, а не к балансу. Можно создать 10 новых ключей — все дадут ту же ошибку если на аккаунте $0.
**Где проверять:** console.anthropic.com → Settings → Billing → Credit balance (должна быть цифра, не просто карта).

## `pdf-parse` на Vercel / Edge Runtime

**Проблема:** `pdf-parse` — Node.js модуль, не работает в Edge Runtime.
**Симптом:** Ошибка компиляции или `Module not found` на проде.
**Решение:** В роуте обязательно указывать `export const runtime = "nodejs"` и в `next.config.ts` добавить `serverExternalPackages: ["pdf-parse"]`.

## Чанкинг коротких текстов

**Проблема:** Если текст < 3 параграфов, разбивка по `\n\n` даёт 1 чанк без заголовка.
**Симптом:** Label чанка = первые 80 символов текста вместо заголовка.
**Статус:** Некритично для MVP, в длинных документах работает хорошо.

## sessionStorage на мобильных

**Проблема:** В Safari Private Mode `sessionStorage` может быть недоступен.
**Симптом:** Пользователь загружает документ, но воркспейс пустой / редирект на лендинг.
**Обходной путь:** Обёрнуто в try/catch, при ошибке — тихий fallback.

---

## Длинные документы и контекстное окно

**Проблема:** Если документ > 100k токенов, весь текст не влезает в контекст Claude.
**Текущее решение:** Передаём только top-4 чанка по keyword scoring.
**Ограничение:** Keyword scoring может пропустить релевантный контент если вопрос сформулирован иначе чем текст документа.
**Будущее решение:** Embeddings + векторный поиск (Phase 2).

## Markdown в ответах Claude

**Проблема:** Собственный `renderMarkdown()` в `TutorPanel` — упрощённый, не покрывает все кейсы.
**Симптом:** Сложная вложенная разметка может отображаться некорректно.
**Обходной путь:** Для MVP достаточно. Если нужно — заменить на `react-markdown`.

## OpenAI SDK в package.json

**Проблема:** В `package.json` осталась зависимость `openai` после переключения обратно на Anthropic.
**Статус:** Не мешает работе, но увеличивает bundle. Можно удалить командой `npm uninstall openai`.

## Переменные окружения при смене ключа

**Проблема:** Next.js dev сервер кэширует `.env.local`. После замены ключа нужно подождать ~2 сек пока сервер сделает "Reload env".
**Симптом:** Старый ключ всё ещё используется после замены.
**Решение:** Смотреть в логах `Reload env: .env.local` — это подтверждение что новый ключ подхвачен.
